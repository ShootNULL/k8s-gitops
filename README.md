# k8s-gitops

Этот репозиторий — единственный источник правды для кластера.
ArgoCD следит за веткой `main` и приводит кластер к тому, что здесь написано.

```
apps/        Application-объекты ArgoCD (по одному на приложение)
n8n/         манифесты n8n + Postgres
```

Хочешшь что-то поменять в кластере — меняй здесь и делай `git push`.
Руками через kubectl не трогать: ArgoCD всё равно вернёт как в git.

Секретов здесь нет и быть не должно: репозиторий публичный.
Secret `n8n-secrets` создаётся в кластере отдельно, руками.
